# 인천 i Minute City 커뮤니티 탐색

인천 커뮤니티 분석 결과를 탐색하는 정적 지도 웹사이트입니다. 별도 서버, API 키, 빌드 과정 없이 실행합니다.

- 범위: 도보 15분 / 1,200m / 4,800m
- 시간: 평일(주간·첨두·야간), 주말(주간·야간), 연휴(주간·야간)
- 사각 그리드 기본 표시, 육각 그리드 전환
- 선택한 커뮤니티 강조, 주요 동 구성·시간별 공간 중첩 비교
- 자료 안내에서 현재 필터 기준 커뮤니티 수·원본 격자 수·표시 면적 확인

## 로컬 실행

저장소 루트에서 실행한 뒤 http://127.0.0.1:8765 를 엽니다.

```sh
python -m http.server 8765 --directory dist
```

## GitHub Pages 배포

1. 공개 저장소에 이 폴더의 내용(`.github` 포함)을 올립니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
3. `main` 브랜치에 반영하거나 Actions의 `Deploy community atlas to GitHub Pages`를 실행합니다.
4. 성공한 배포 작업에 실제 공개 URL이 표시됩니다.

모든 사이트 자산·데이터는 상대경로를 사용하므로 프로젝트 하위 경로에서도 작동합니다.

공식 배포 문서: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## 데이터 해석 및 처리

- 제공 GPKG 3개 조건 × 7개 시간 구분을 변환한 자료입니다. 원본 GPKG 및 이동 개별 기록은 저장소에 포함하지 않습니다.
- UI의 자전거·자동차 아이콘은 거리 조건을 구분하는 시각 기호입니다. 원본 분석을 실제 자전거·자동차 이동 분석으로 변경하지 않았습니다.
- `0609`는 사용자 요청에 따라 연휴 탭에 배치했습니다. 제공 파일에는 정확한 날짜 정의가 없어 추석 해당 여부는 확인되지 않았습니다.
- 기본 최소 격자는 10개입니다. 자료 안내 집계는 현재 조건과 최소 격자 필터를 반영합니다. 선택 커뮤니티나 검색 결과만의 집계가 아닙니다.
- 면적은 EPSG:5179에서 원본 격자 면적을 합산했습니다. 동 구성 비율은 격자 수 기준입니다. `n_rows`는 이동량·인구로 해석하지 않습니다.
- 시간 비교는 선택한 원본 격자 집합과 각 시간대 커뮤니티 사이의 최대 자카드 중첩률입니다.
- 색은 기존 공통 식별자 대응표를 이용합니다. 색 하나만으로 동일 커뮤니티를 뜻하지 않으며 원본 번호는 조건·시간별입니다.
- 표시용 사각·육각 그리드는 웹지도 EPSG:3857에서 정비율로 구성합니다. 사각의 지상 길이는 북위 37.5°에서 약 250m, 육각은 같은 면적의 가로형 정육각입니다. 각 표시 셀은 원본 영역과의 중첩 면적이 가장 큰 커뮤니티로 배정합니다.
- 분석 결과를 다시 계산한 것이 아닙니다. 집계는 원본 육각 격자 기준으로 유지합니다. 실제 토지이용·인구·시설 기능은 추정하지 않습니다.
- 배경 타일은 OpenStreetMap에서 불러옵니다. 배경지도에는 인터넷 연결이 필요합니다.

## 공개용 파일 구성

GitHub용 배포본에는 사이트 실행에 필요한 파일, 재생성 스크립트, 문서만 포함합니다. 개인 PC 경로, Sites 계정 설정(`.openai`), Git 인증정보, 원본 연구 폴더와 개발 중간 파일은 제외합니다.

이 저장소는 연구 데이터에 새로운 재사용 라이선스를 임의로 부여하지 않습니다. 외부 자산의 라이선스는 `THIRD_PARTY_NOTICES.md`와 `dist/vendor`를 참조하세요.
